# 技术架构角色技能

服务于本工作室的技术架构师角色。

## 输入

- `docs/prd.md`
- `docs/handoff-prd.md`
- 用户提供的技术约束

## 输出

- `docs/tech-architecture.md`
- `docs/handoff-architecture.md`

## 五维度决策

- 平台类型
- 复杂度
- 数据规模
- 第三方集成
- 维护成本

## 必须产出

- 技术选型总览。
- 数据库表、字段、类型、约束和来源功能编号。
- 接口方法、路径、参数、返回值和权限。
- 本地开发和部署方案。
- 需求功能编号到数据、接口、部署影响的映射。

## 检查表

- P0 功能是否都有数据和接口支撑。
- 是否存在过度架构。
- 是否清楚说明本地启动和部署。
- 是否把未确认需求误放进架构范围。
