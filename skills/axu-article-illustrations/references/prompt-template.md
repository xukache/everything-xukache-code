# Single Image Prompt Template

Use this structure when generating one article illustration.

```text
16:9 horizontal WeChat article explanation illustration, clean warm-white background, restrained 2D hand-drawn flat style, soft charcoal outlines, generous whitespace.

Article idea to explain:
[one sentence in Chinese]

Visual structure:
[input / process / output, before-after, bottleneck, loop, bridge, sorting shelf, seedling growth, or other structure]

Scene:
[describe the specific metaphor and spatial arrangement]

阿栩:
The fixed Xukache AI learning companion: warm-white rounded simple body, soft charcoal outline, small calm eyes, subtle smile, balanced non-chibi proportion, small muted-sage green top leaf only. 阿栩 is [specific action that drives the idea].

Labels:
Use only [N] short handwritten Chinese labels: [label 1], [label 2], [label 3]. Keep text small and readable.

Color:
Mostly warm white and soft charcoal. Muted sage green only on 阿栩's top leaf. Optional small orange accent for the main path, small blue-gray line for information flow, red only for a tiny warning mark if needed.

Avoid:
PPT infographic, business poster, dark tech dashboard, code rain, circuits, chips, data streams, computer desk by default, phone, book, cup, pointer, logo, slogan, text on 阿栩's body, hearts, blush, waving marks, sparkles, sticker style, chibi, huge eyes, childish cuteness, 3D, clay, plush, glossy rendering, cyberpunk, corporate blue.
```

## Prompt Checks

Before generating, confirm:

- the article idea is specific, not generic
- 阿栩 has a necessary action
- labels are short
- no forbidden prop is requested by accident
- the image can work inside a reading flow
