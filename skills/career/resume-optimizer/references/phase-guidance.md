# 阶段引导

每进入一个主要阶段，都要用简短提示让用户知道当前在做什么。

## 阶段 1：材料接收

```text
当前阶段：材料接收。
我会先把你提供的简历、JD、项目、仓库和个人资料整理成事实底座。现在不急着改写，目标是弄清楚哪些内容可以安全、扎实地写进简历。
```

## 阶段 2：JD 拆解

```text
当前阶段：JD 拆解。
我会把目标岗位翻译成筛选标准：业务目标、硬技能、软能力、隐性门槛、加分项和风险点。产出会是一张匹配矩阵，告诉你哪里证据强、哪里证据弱、哪里不建议硬写。
```

## 阶段 3：经历证据挖掘

```text
当前阶段：经历证据挖掘。
我会把你的经历转成可写入简历的证据：背景、角色、行动、结果、产出物、难点和面试追问潜力。
```

## 阶段 4：简历策略规划

```text
当前阶段：简历策略规划。
我会先确定主叙事、黄金广告位内容、项目顺序、版本策略和风险处理方式，再进入正式改写。
```

## 检查点 1：策略确认

```text
检查点：策略确认。
正式改写前，请确认目标方向、简历主叙事、重点经历和包装边界。这样可以避免简历变得“文字漂亮但策略错误”。
```

## 阶段 5：简历改写

```text
当前阶段：简历改写。
我会按确认后的策略，用 JD 语言、STAR/PAR 结构、可量化结果和清晰贡献边界来改写选定内容。
```

## 阶段 5b：模板化简历生成

```text
当前阶段：模板化简历生成。
我会把已确认的简历内容写入 Markdown 内容源，而不是直接修改 HTML。HTML 模板会加载这份 Markdown 并实时渲染，方便你只维护内容、不碰版式代码。
```

## 阶段 6：审查

```text
当前阶段：审查。
我会从三个角度检查草稿：是否匹配 JD、证据是否可信、面试时是否讲得住。
```

## 阶段 7：修复

```text
当前阶段：定向修复。
我会只修复最小失败片段，不整份重写，尽量保留已经正确的部分。
```

## 阶段 8：面试表达

```text
当前阶段：面试表达辅导。
我会把简历中的重点经历转成 30 秒版本、2 分钟版本、深挖版本、高频追问和风险问题回答策略。
```
