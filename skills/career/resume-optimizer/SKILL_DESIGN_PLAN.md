# 简历优化 Skill 设计计划

## 1. Skill 目标

构建一个可复用的简历优化 Skill，帮助用户从原始材料走到岗位定制简历和面试表达准备。

这个 Skill 不应该像一次性的“简历润色提示词”，而应该像一套可控的咨询式 Harness：

1. 理解目标岗位。
2. 归一化用户材料。
3. 建立经历证据库。
4. 规划简历策略。
5. 在高影响决策点让用户确认。
6. 生成目标岗位定制版简历。
7. 从多个视角审查。
8. 只修复最小必要片段。
9. 准备面试沟通表达。

## 2. 参考来源

开发时同时吸收当前项目中的两份文档：

- `../../../简历优化SOP.md`：作为 Harness 流程和服务步骤的主骨架。
- `../../../用面试官的思维写简历.md`：作为面试官视角、STAR/PAR、黄金广告位、模块排序、风险感知和说服力原则的来源。

不要整篇搬运两份文档。应将其中方法论重组为按阶段加载的 reference 文件，重复内容不重复写入。

## 4. SKILL.md 设计

`SKILL.md` 保持精简，只做流程编排层。

它应包含：

- frontmatter 中的名称和触发描述；
- 何时使用本 Skill；
- 执行原则；
- 工作区约定；
- Phase 流程；
- 检查点规则；
- references 和 templates 的路由规则；
- 交付物预期。

详细方法放在 `references/` 中，输出格式放在 `templates/` 中。

## 5. Phase 流程

### 阶段 0：初始化引导与任务分流

当用户提出简历优化、岗位匹配、简历诊断、项目转简历、面试准备等请求时触发。

如果用户材料不足，温和引导。不要要求用户一次性准备所有材料。

### 阶段 1：材料接收

收集并归一化：

- 当前简历；
- 目标公司和 JD；
- 个人资料；
- 工作、实习、科研、比赛和项目材料；
- 代码仓库或作品集；
- 城市、岗位级别、时间线和面试阶段等约束。

### 阶段 2：JD 拆解

将每个 JD 拆成：

- 业务目标；
- 硬技能；
- 软能力；
- 隐性门槛；
- 加分信号；
- 风险点。

判断岗位招聘诉求：扩充团队、补齐能力或培养梯队。

### 阶段 3：经历证据挖掘

用 STAR/PAR 把用户经历转为证据库：

- 背景；
- 目标；
- 角色；
- 行动；
- 难点；
- 结果；
- 产出物；
- 复盘；
- 面试追问潜力。

### 阶段 4：简历策略规划

生成简历计划：

- 目标岗位优先级；
- 简历主叙事；
- 黄金广告位内容；
- 经历筛选；
- 版本策略；
- 包装边界；
- 需要处理的风险。

### 检查点 1：策略确认

正式改写简历前必须暂停，让用户确认：

- 目标岗位优先级；
- 简历主叙事；
- 要重点强调的经历；
- 真实性和包装边界；
- 是否需要多版本简历。

### 阶段 5：简历改写

根据上下文生成母版简历或目标岗位定制版。

使用：

- 与 JD 对齐的模块顺序；
- 黄金广告位优先级；
- STAR/PAR bullet；
- 可量化或有产出物支撑的结果；
- 清晰的个人贡献边界。

### 阶段 6：多视角审查

用三个视角审查：

1. JD 匹配审查；
2. 证据可信审查；
3. 面试可讲审查。

### 阶段 7：最小切片修复

只修复最小失败单元：

- 摘要；
- 技能区；
- 单个项目；
- 单条 bullet；
- 风险解释；
- 面试表达点。

### 检查点 2：最终简历确认

询问用户是否需要：

- 最终交付；
- 针对某家公司微调；
- 格式转换；
- 面试辅导；
- 继续局部修复。

### 阶段 8：面试表达辅导

为每个关键经历准备：

- 30 秒版本；
- 2 分钟版本；
- 深挖版本；
- 高频追问；
- 风险问题回答策略。

## 6. 引导层

需要为以下场景加入明确引导：

- 首次直接运行；
- 每个阶段开始；
- 每个检查点；
- 用户材料不完整；
- 多 JD 场景；
- 用户反馈和修复请求。

这个引导层要让用户即使只说“帮我优化简历”，也能顺利进入流程。

## 7. 质量标准

这个 Skill 成功的标准：

- 不直接跳到润色；
- 明确岗位匹配逻辑；
- 用证据替代空泛表达；
- 区分策略和改写；
- 在高影响决策前让用户确认；
- 产出的简历内容用户能在面试中讲得住；
- 审查 JD 匹配、真实性和面试可讲性；
- 局部修复，不破坏已有正确内容。

## 8. 初始开发步骤

1. 创建 Skill 目录和设计计划。
2. 编写 `SKILL.md`。
3. 创建初始化引导和阶段引导 reference。
4. 将核心简历方法拆成阶段 reference。
5. 添加可复用模板。
6. 按质量标准做结构检查。
