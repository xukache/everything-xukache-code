# Article Illustration Style

## Purpose

阿栩 article illustrations explain the article. They should feel like calm visual thinking notes inside a WeChat post, not standalone posters.

## Canvas

- 16:9 horizontal image.
- Clean white or warm-white background.
- Generous whitespace.
- A few hand-drawn elements only.
- 阿栩 participates in the core action.

## Visual Language

Use a restrained hand-drawn structure style:

- soft charcoal linework
- warm-white background
- muted sage only for 阿栩's top leaf
- small blue or gray lines for information flow only when useful
- small orange accents for the main path only when useful
- red only as rare warning marks
- short handwritten Chinese labels, usually 2-6 characters each

Use labels sparingly. A good image should still make sense if labels are reduced.

## Good Structure Types

- before and after
- input, process, output
- bottleneck and release
- scattered pieces becoming a reusable asset
- one path splitting into choices
- small loop or flywheel
- stack, shelf, bridge, seedling, container, filter, scale, compass, map, or path metaphors
- a common mistake beside a correct route

## Avoid

- PPT information graphics
- business poster composition
- dark tech dashboard
- cyber AI visual clichés
- dense system architecture
- large UI panels
- generic person at computer
- cute sticker sheets
- too many arrows and labels
- title text in the upper-left corner like "流程图" or "方法论"

## Composition Rules

Each image explains one idea. Do not cram several article sections into one image.

阿栩 should be:

- near the action
- touching, carrying, sorting, tending, checking, or connecting the key element
- scaled modestly so the idea remains readable

Keep environmental props abstract and low-detail. If a prop is not needed to explain the article idea, remove it.
