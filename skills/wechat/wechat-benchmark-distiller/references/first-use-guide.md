# 第一次使用引导

当用户第一次使用本 Skill，或只说“帮我蒸馏对标公众号”“我想学某几个公众号”但没有给清楚样本时，使用下面的初始化文案。

## 初始化文案

我可以帮你把对标公众号的文章拆成一套可复用的写作方法，但不会直接“仿写某个作者”。流程会先做文章类型分类，再分别蒸馏每个账号，最后融合成适合你自己公众号的写作规则。

正式接收材料前，我会先创建本次蒸馏的文件夹结构，用来放原始素材、样本索引、分类结果、账号画像和最终规则。原始文章不会放进 Skill 目录，而是放到本次任务的 `raw-materials/` 下面。

你可以这样给我材料：

1. **单账号蒸馏**
   给我一个公众号的 3-5 篇代表文章，最好是同一种或相近类型。适合先搞清楚这个账号到底强在哪里。

2. **多账号融合**
   给我 2-4 个对标账号，每个账号 2-5 篇文章。我会先分别分析，再判断哪些账号适合借结构、哪些适合借标题、哪些适合借语言或案例展开。

3. **指定单一风格**
   如果你明确说“这次只学某个账号”，我会只参考这个账号，但仍然只提取写作方法，不复制作者人格和私人口吻。

4. **只做框架**
   如果你暂时没有文章样本，我可以先给你一个待填充的蒸馏框架，但结论会标为“未基于样本验证”。

5. **只给公众号名称**
   如果你没有整理文章链接，只给我公众号名称也可以。我会先用 `wechat-article-archive` 的 mptext API 流程搜索公众号、拉取历史文章列表，再选择样本归档成 Markdown。

最好按这个格式发我：

```md
目标：单账号蒸馏 / 多账号融合 / 指定单一风格 / 先做框架

我的公众号方向：
我希望学到：
我明确不想学：

对标账号 A：
- 文章 1：标题 + 链接 / 正文 / 截图 / 摘录
- 文章 2：
- 文章 3：

或只写：
- 公众号名称：
- 希望抓取：最近 10 篇 / 最近 20 篇 / 某个主题关键词

对标账号 B（如果有）：
- 文章 1：
- 文章 2：
```

如果你只想先快速开始，直接发：

```md
我想做多账号融合。
我的公众号方向是：
这些是对标文章：
1.
2.
3.
```

我会先输出一张文章类型分类表，确认每篇文章属于观点判断、教程实操、案例复盘、经验方法、工具推荐、故事共鸣、热点借势还是个人 IP。分类完成后，才会进入账号风格和语言结构蒸馏。

如果你还没有指定目录，我会默认创建：

```text
benchmark-distillations/<本次蒸馏主题>/
  raw-materials/
  analysis/
    sample-map.md
    article-type-classification.md
  synthesis/
  deliverables/
```

如果你给的是一批公众号链接，我会先用 `wechat-article-archive` 把链接归档成 Markdown，再写入这个目录结构。如果你只给公众号名称，我会先通过 API 获取文章列表，再把选中的文章链接归档进来。

## 不要一次问太多

如果用户已经给出部分材料，不要再完整复述上面的文案。只问一个最关键的缺口，例如：

- “这些文章分别属于哪个公众号？如果不知道，我可以先按来源 A/B 处理。”
- “你这次是想综合多家优点，还是只学其中一个账号？”
- “你希望最终产物是分析报告，还是能直接用于写下一篇文章的模板？”

## 样本不足时的提醒

样本不足时要明确说明：

- 1 篇文章只能做单篇拆解，不能代表账号风格。
- 同类型 3 篇以上，才能比较稳地总结该类型写法。
- 一个账号 5 篇以上且类型多样，才适合总结账号级写作画像。
- 多账号融合必须先分别蒸馏，不能把样本混在一起平均。
