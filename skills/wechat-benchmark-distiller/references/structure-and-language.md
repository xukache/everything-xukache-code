# 结构和语言蒸馏

文章类型分类完成后使用本文件。

## 单篇文章拆解

对每篇代表性样本输出：

```md
## <文章标题>

类型：
读者状态：
文章承诺：

### 结构地图
1. 标题：
2. 开头：
3. 铺垫：
4. 第一次转折：
5. 主体章节：
6. 例子 / 证据：
7. 最后一次转折：
8. 结尾：

### 读者路径
阅读前：
阅读中：
阅读后：

### 可迁移动作
- ...

### 弱点或不可迁移动作
- ...
```

## 结构维度

### 标题

提取：

- 承诺类型：结果、冲突、好奇、身份、方法、故事、警告
- 主体对象：读者、作者、工具、趋势、问题、案例
- 具体程度：模糊 / 具体 / 具名
- 压力强度：低 / 中 / 高
- 副标题是否承载真正承诺

### 开头

分类：

- 结果前置
- 场景先行
- 冲突先行
- 问题先行
- 诊断先行
- 个人坦白
- 直接给结论

记录：

- 多快进入观点
- 前 300 字让读者想知道什么
- 背景信息是必要还是装饰

### 章节顺序

常见结构：

- 问题 -> 诊断 -> 方法 -> 例子 -> 行动
- 故事 -> 转折 -> 反思 -> 原则
- 观点 -> 理由 -> 反对意见 -> 结论
- 结果 -> 过程 -> 可复用规则
- 趋势 -> 角度 -> 影响 -> 个人选择

不要把所有文章强行塞进模板。描述真实顺序。

### 证据位置

追踪证明出现在什么位置：

- 观点之前
- 观点之后立刻出现
- 情绪铺垫之后
- 截图 / 过程细节中
- 对比表中
- 作为反面案例

### 结尾

分类：

- 实际下一步
- 轻轻收束的反思
- 价值表达
- 评论 / 分享 / 购买号召
- 开放式余味
- 回到开头意象

## 语言维度

### 句子节奏

记录：

- 平均句长：短 / 中 / 长
- 段落长度
- 单句成段频率
- 列表和编号使用情况
- 更像口语还是书面语

### 信息密度

分类：

- 高：概念压缩，默认读者有背景
- 中：概念配例子解释
- 低：节奏慢、友好、过渡多

### 词汇

追踪：

- 反复出现的动词
- 连接词
- 领域术语
- 口语表达
- 判断词
- 缓和词

除非用户明确拥有或需要某个通用表达，否则不要复制精确口头禅。

### 抽象阶梯

观察文章如何在这些层级间移动：

- 具体场景
- 具体例子
- 方法
- 原则
- 世界观

好的蒸馏要识别这种移动方式，而不是只记词汇。

### 情绪温度

分类：

- 冷静分析
- 温暖陪伴
- 尖锐批判
- 兴奋发现
- 克制私人化
- 焦虑紧迫

说明情绪温度来自哪里：词汇、标点、节奏、例子，还是标题。

## 语言规则输出

规则要写成动作，不要写成形容词。

弱：

- “语言犀利、有洞察。”

强：

- “反驳常见观点时，先用一句短句给判断，再用下一段指出这个观点背后的隐藏假设。”
