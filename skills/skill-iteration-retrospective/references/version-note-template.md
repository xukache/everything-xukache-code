# 版本说明模板

在提出或完成一次 Skill 迭代后，使用这个模板记录版本说明。目标不是只记录“改了什么”，而是保留“为什么要这样改”。

## 版本说明

```text
Skill：
版本：
日期：
作者：

迭代目标：
- 

本次处理的失败样本：
- 

已做或建议的修改：
- 触发条件：
- 必填输入：
- 判断规则：
- 输出接口：
- 停止条件/职责边界：
- 审阅或暂停节点：
- 参考资料/模板：

修改原因：
- 

修改后的预期行为：
- 

已知取舍：
- 

验证计划：
- 旧失败样本回放：
- 新样本试跑：
- 输出交接检查：
- 职责边界检查：
- 版本管理格式检查：

下一轮观察点：
- 
```

## 失败模式库条目

```text
失败模式：
出现位置：
表现症状：
根本原因：
预防规则：
正确停止动作：
示例：
```

## 写作规则

- 写给未来维护者看，不只是写给当前作者看。
- 每个修改都要能关联到失败样本、明确迭代目标或已经观察到的交接问题。
- 记录本次刻意没有修改的内容。
- 保持简洁，让下一轮迭代前可以快速读完。
