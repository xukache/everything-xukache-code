# Skill 迭代卡模板

使用这个模板，为指定 Skill 建立或更新维护卡。未知字段要标记为待确认问题，不要当成事实。

## 基础信息

```text
Skill 名称：
Skill 路径：
当前版本：
负责人：
上次更新时间：
上次修改人：
```

```text
- 

完成线：
- 

禁用或后置产物：
- 
```

## 评审提示词

```text
请基于这张迭代卡，检查目标 Skill 是否具备清晰的触发条件、必填输入、输出对象、输出格式和停止条件。只指出会影响真实使用的缺口，不做泛泛的文案润色。
```
