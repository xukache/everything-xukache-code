# 视觉审查参考

设计审查必须基于运行中的原型截图，不能只看代码或文档。

## 截图要求

- 候选方向：`prototype/directions/index.html` 和每个方向页。
- 完整原型：`prototype/index.html` 和所有 P0 页面。
- B 端项目至少覆盖 `1280x800`、`1440x900`，需要时补 `1920x1080`。
- 非 B 端项目按目标设备覆盖 desktop/tablet/mobile。
- 截图保存到 `prototype/review/screenshots/`，文件名要包含页面、状态和视口。

## 审查维度

- 视觉层级：主任务和主操作是否最明显。
- 信息架构：用户路径是否自然，页面边界是否清楚。
- 一致性：tokens、间距、控件、状态、图标和文案是否统一。
- 响应式：不是简单缩放，而是合理重排。
- 状态：加载、空、错误、成功、禁用、权限异常是否可见。
- 可访问性：对比度、键盘焦点、语义结构、触控尺寸。
- 审美方向：是否符合已选方向，是否有通用 AI 味。

## 输出要求

- 每个问题必须引用截图路径或页面路径。
- 问题按阻塞、应修、可优化排序。
- 已修正问题要有复查截图或复查说明。
