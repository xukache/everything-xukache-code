# 开发任务规划角色技能

服务于本工作室的开发规划师角色。

## 输入

- `docs/prd.md`
- `docs/tech-architecture.md`
- `docs/ui-design.md`
- `prototype/`

## 输出

- `docs/dev-tasks.md`

## 任务拆解原则

1. 每个任务独立可验证。
2. 每个任务尽量控制在 5-20 分钟执行粒度。
3. 用 `Txxx` 编号标注任务。
4. 明确前置依赖，避免循环依赖。
5. 每个任务都要有执行指令、涉及文件、验证方式和边缘情况。

## 检查表

- 是否覆盖所有 P0 功能。
- 是否每个任务完成后都能看到或验证结果。
- 是否有需求功能编号到任务编号的映射。
- 是否避免“先建数据库、再接口、最后页面”这种不可见拆分。
