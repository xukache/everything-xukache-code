# 配图工作流

配图要服务文章真实过程。不要为了填充版面添加装饰图。

## 动态更新原则

`visual-plan.md` 是动态文件，不是一开始生成后就不再调整。

必须在这些节点更新：

- 大纲确认后：生成初版配图计划，只列可能需要的图片和截图。
- 初稿完成后：根据真实段落重新检查每张图是否仍然需要。
- 用户修改初稿后：同步增删图片位置，避免配图计划和正文脱节。
- 用户补充原始素材、项目链接、截图或对话记录后：更新图片来源和动作。
- 最终交付前：确认正文中实际插入的图片和 `visual-plan.md` 一致。

会话里不要只说“需要配图”，要把更新写回 `visual-plan.md`。

## 图片分类

每个图片位置都要归类为以下之一：

- 固定顶图
- 固定底图
- 仅封面使用的图片
- 已有正文图片
- 从本地 HTML、应用或文件截图
- 用户提供的截图
- 项目链接或本地页面截图
- 生成式插图提示词
- 等待用户处理的占位

## 对话记录处理

如果用户提供了原始对话记录文档，优先从文档中提取关键对话，写成正文对话块。

不要默认要求用户提供对话截图。只有在以下情况才考虑对话截图：

- 用户明确要求展示真实聊天界面。
- 对话界面本身是文章要讲的产品或工作流证据。
- 文本摘录不足以说明上下文，需要截图辅助。

否则，使用文本对话更清晰，也更方便公众号排版。

## 项目链接截图

如果用户提供项目链接、本地 HTML 页面、预览地址、部署地址或可运行页面，应优先判断是否可以截图补充文章证据。

适合截图的对象：

- 项目首页或核心页面
- 执行结果页面
- 文件结构或交付物页面
- 配置页、确认页、预览页
- 能证明“这一步真的做出来了”的界面

截图原则：

- 截图必须服务正文观点，不为了装饰而截图。
- 截图放在说明它的段落附近。
- 图片文件放入 `images/`，原始链接和截图说明记录到 `visual-plan.md`。
- 如果链接需要登录或无法访问，在 `visual-plan.md` 中标记阻塞原因，不要编造截图。

## Axu 配图 Skill

当任务涉及公众号封面、顶图、底图、Axu/Xukache 风格正文插图或生成式配图提示词时，如果 `axu-article-illustrations` 可用，必须使用它。

它适合协同处理：

- 封面图生成
- 固定顶图和底图资产
- 正文解释图
- 供用户生成图片的提示词

禁止路径：

- 禁止把生成式插图任务改写成 HTML 设计任务。
- 禁止在未调用 `axu-article-illustrations` 的情况下自行设计 Axu/Xukache 风格图。
- 禁止因为能用 HTML、SVG、CSS 或临时页面画出来，就跳过配图 skill。
- HTML、SVG、CSS 或临时页面只能用于用户明确要求的排版预览，或用于截取已有页面证据。
- 如果 `axu-article-illustrations` 不可用，必须在 `visual-plan.md` 标注阻塞或改用占位，不得自行替代。

## 固定资产规则

对于 Axu 风格公众号文章：

- 顶图和底图是稳定文章资产，除非用户明确要求修改。
- 不要随意重新设计固定顶图和底图。
- 封面图可以生成并保存在 `cover/` 下，但不要默认作为正文开头图片插入。
- 如果用户说“封面图我生成了就可以了，不需要插入文章中”，正文中就不要插入封面图。
- 固定底图下方必须增加一行 `#tag` 标签。标签不属于图片内容，不要画进底图里。

## 截图规则

文章需要截图时：

- 优先使用真实本地截图，不要编造示意图。
- 截图要放在解释它的章节附近。
- 截图还不存在时，使用清晰占位。
- 如果已有项目链接可访问，优先从项目页面截图，而不是让用户额外手动截图。
- 如果截图用于支撑正文关键判断，不能只写在 `visual-plan.md`。必须在 `draft.md` 对应段落插入截图占位或规则摘录占位。

占位格式：

```markdown
[截图占位｜说明要截什么]

建议截图：path-or-page
用途：说明这张截图为什么对读者有用。
```

## 生成图片提示词占位

需要用户后续生成图片时，放置提示词块：

```markdown
[配图生成占位｜image-name.png]

使用：$pm-workflow:axu-article-illustrations
提示词：
...
```

生成式配图提示词也属于 Axu 配图 Skill 范围。不要绕过该 skill 自行写一套视觉提示词体系。

## 配图计划输出

插图前先产出简短配图计划：

| 章节 | 图片 | 来源 | 动作 |
| --- | --- | --- | --- |
| 开头 | article-hero-watering.png | 固定资产 | 插入 |
| Skill 介绍 | CK2 截图 | 本地 HTML 截图 | 截图 |
| 交付物 | deliverables 截图 | 用户截图 | 插入 |
| 结尾 | article-footer-growth.png | 固定资产 | 插入 |
| 底图下方 | #AI #Codex #AI编程 | 内容标签 | 自动识别，最多 5 个 |

每次正文结构变化后，都要复查这张表，删除不再对应正文的图片，新增能支撑新段落的截图或配图。
