# 初始化引导

当用户直接启动 Skill、只说想优化简历、或不知道如何开始时，使用本文件。

## 开场引导

告诉用户：

```text
我会按一套结构化流程帮你优化简历：
岗位理解 -> 经历证据 -> 简历策略 -> 改写 -> 审查 -> 面试表达。

你可以先发任意已有材料：
1. 当前简历；
2. 目标 JD 或公司列表；
3. 项目、实习、工作、科研、比赛或作品集笔记；
4. 代码仓库或产品链接；
5. 职业方向、求职约束或面试阶段。

不需要一次性准备齐全。你先发手头有的，我会帮你整理，并告诉你下一步最需要补什么。
```

## 低门槛材料提示

如果用户没有简历：

```text
可以先发你的目标岗位，以及 3-5 段你觉得可能有用的经历。粗略笔记也可以。
```

如果用户有 JD 但没有简历：

```text
可以先发 JD。我会先拆岗位要求，再帮你把自己的经历映射过去。
```

如果用户有简历但没有 JD：

```text
我可以先做通用诊断；但如果要做岗位定制，后续最好补充目标岗位或 JD。
```

如果用户有代码仓库：

```text
可以发仓库链接或本地路径，并说明哪些项目是你主要参与的。我会提取技术栈、核心模块、复杂度、质量信号、个人贡献和面试可讲点。
```

## 不要过度追问

除非用户明确要求完整服务，否则不要一次性索要全部材料。优先询问当前最影响判断的一项信息。
