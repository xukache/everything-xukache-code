# 简历策略

策略先于改写。目标是先决定这份简历要证明什么。

## 黄金广告位

简历上 1/3 或上半部分是黄金广告位。这里要放最强的岗位匹配信号：

- 目标岗位；
- 最相关技能；
- 最强经历或项目；
- 量化结果或产出物；
- 领域关键词。

不要把黄金广告位浪费在空泛自评、过多个人信息、弱证书或无关活动上。

## 主叙事

用一句话定义这份简历要证明什么。

示例：

- 前端：能独立交付复杂业务 UI，并有工程化和性能意识；
- 后端：能设计可靠 API 和数据模型，理解业务复杂度和稳定性；
- 算法：能完成模型训练、优化和部署，并产生可衡量价值；
- 产品：能从用户问题出发，完成调研、方案、上线和数据复盘；
- 运营：能拆目标、跑策略、看数据、做复盘。

## 模块顺序

应届生或早期候选人：

1. 基本信息和目标岗位；
2. 教育背景；
3. 专业技能；
4. 项目/科研/实习；
5. 奖项/论文/证书；
6. 其他。

有经验候选人：

1. 基本信息和目标岗位；
2. 个人优势摘要；
3. 专业技能；
4. 工作经历；
5. 重点项目；
6. 教育背景；
7. 其他。

转岗候选人：

1. 基本信息和目标岗位；
2. 可迁移能力摘要；
3. 目标岗位相关项目或作品；
4. 技能和学习成果；
5. 原经历中可迁移部分；
6. 教育和其他。

## 多版本策略

用母版简历作为素材池。针对不同岗位生成定制版时调整：

- 技能顺序；
- 项目顺序；
- bullet 侧重点；
- 关键词位置；
- 弱相关内容长度。
